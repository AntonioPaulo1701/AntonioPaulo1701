## 🧑‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e trabalho com **desenvolvimento backend**, com foco em três coisas:

- **APIs e serviços** bem estruturados, com banco de dados modelado do jeito certo desde o começo.
- **Automação de processos** — se é repetitivo e manual, provavelmente dá para automatizar.
- **Integração com IA** aplicada a problemas reais: atendimento, cobrança e análise de dados.

Meu projeto principal hoje é um sistema financeiro e de prontuário digital rodando em produção em uma clínica odontológica, que substituiu planilhas e cobrança manual por um fluxo automatizado.
